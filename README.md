# עדי טורס · מיכל ועדן בתאילנד

אפליקציית נסיעה בעברית שמותאמת לנייד: מסלול לפי תאריכים, פרטי טיסות ומלונות, מפות, מסמכים לצפייה ולפתיחה כ־PDF, תשלומים ושמירה לשימוש ללא אינטרנט.

## פרסום ב־GitHub Pages

1. פתחי מאגר חדש ב־GitHub.
2. חלצי את ה־ZIP והעלי **את תוכן התיקייה** לשורש המאגר, כולל `assets` ו־`.github` (חשוב לא להשמיט את התיקייה הזו).
3. ב־Settings → Pages בחרי **GitHub Actions** כמקור הפרסום.
4. שמרי את הקבצים בענף `main`. ה־workflow הכלול יפרסם את האתר. אם הקבצים כבר נשמרו, הריצי את `Publish travel app` ידנית דרך Actions.
5. הקישור יופיע ב־Settings → Pages לאחר הפרסום. שלחי אותו למיכל ולעדן.

אפשר גם לבחור Deploy from a branch → main → /(root) במקום GitHub Actions. האתר סטטי ואינו צריך התקנה או Build.

## שימוש בנייד

- לחיצה על מקטע פותחת את פרטי הנסיעה והמסמכים שלו.
- ״כל המסמכים״ מרכז את אישורי ההזמנה וכרטיסי העלייה למטוס.
- לחצי על ״שמירה לשימוש בלי אינטרנט״ כשהמכשיר מחובר, והמתיני להודעת ההשלמה. כל המסמכים, התמונות והמדריך יישמרו בדפדפן. לאחר שמירה בדקי פתיחה במצב טיסה לפני הנסיעה. מחיקת נתוני הדפדפן או פינוי אחסון עשויים להסיר את העותק השמור. מפות דורשות חיבור.
- באייפון: Safari → שיתוף → הוספה למסך הבית. באנדרואיד: Chrome → התקנת אפליקציה / הוספה למסך הבית.

## תוכן ופרטיות

הפרויקט מכיל מסמכי נסיעה אמיתיים, שמות ומספרי הזמנה. פרסום ב־GitHub Pages הופך את האתר ואת הקבצים לזמינים לכל מי שמגיע לקישור; אין בפרויקט מסך כניסה או הגנת סיסמה. לפרסום עם הגבלת גישה יש להשתמש באחסון שמספק אותה.

פרטי ההלוך של איתיחאד מבוססים על כרטיסי העלייה למטוס החדשים. פרטי החזור הבינלאומיים מבוססים על אישורי ההזמנה המקוריים. PG138 ב־27.10 הוא החזור המעודכן מקוסמוי. ב־Cocohut הסדר התשלום המעודכן הוא 50% לחיוב ו־50% במזומן; לא הונח שהחיוב כבר בוצע. שעות ורציפים למעבורות לא הומצאו ומסומנים כדורשים השלמה.

## עריכה ובדיקה מקומית

- `app.js`: מסלול, שעות, מלונות ותשלומים.
- `documents.json`: קישורים לקובצי המסמכים ולתמונות העמודים.
- `style.css`: עיצוב.
- `sw.js`: שמירה בלי אינטרנט. לאחר שינוי משמעותי יש לעדכן את שם המטמון ולהוריד שוב דרך כפתור השמירה.
- `assets/docs`: קובצי PDF; `assets/previews`: תמונות לצפייה בתוך האפליקציה.

לבדיקה מקומית הריצי `python3 -m http.server 8000` בתיקייה ופתחי `http://localhost:8000`. אין תלויות חיצוניות, API, אנליטיקה או ספריות צד שלישי.

הקבצים נבדקו תחבירית וכל קישורי המסמכים נבדקו. התנהגות PWA ושמירה במצב טיסה דורשת בדיקה בדפדפן ובמכשיר לאחר פרסום.
